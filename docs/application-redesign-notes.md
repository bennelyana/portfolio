# Application screen redesigns

Created with the built-in image generation tool as portfolio UI concepts. These replace the portfolio preview images; they do not modify the underlying applications. Original screenshots remain in public/projects.

## Prompt set

Common instruction: Redesign the application interface in the edit target as a polished high-fidelity portfolio UI concept. Make a substantial visual improvement, not just sharpening. Flat front-facing app screen only, no external device, no surrounding portfolio card, no watermark. Clean modern typography, consistent spacing, restrained shadows, aligned controls, highly legible text. Keep existing project identity, functional content and data; do not invent analytics or new capabilities.

- `public/projects/medical-system-redesign.png`: Landscape medicine inventory; white/light slate workspace, narrow navy sidebar, teal-blue accents. Preserve Sales List, navigation, sales rows, search, New Sales, Edit and Delete. Modern table with understated red destructive actions. I&J Medical System identity.
- `public/projects/biao-guianga-redesign.png`: Landscape Biao Guianga Health Center login in emerald and white. Preserve two official seals, landscape photo, Username, Password, Log in and Create account. Branded left panel and white login form on the right.
- `public/projects/todo-list-redesign.png`: Portrait white and emerald task editor. Edit task header, Task title and Description labels, Playing Basketball values, existing food attachment, Save Changes and Cancel. No added scheduling or priority features.
- `public/projects/sari-sari-inventory-redesign.png`: Landscape DEW Sari-Sari Store inventory in ivory, navy and terracotta. Customer and quantity form, five category selectors, clean table. Preserve Anna and Mark records and Add, Update, Delete, Pay and Inventory controls. No charts or statistics.
- `public/projects/sari-sari-login-redesign.png`: Two stacked login and registration screens, coordinating ivory, navy and terracotta. Store photo and white forms. Preserve Username, Password, Login, Register, Exit and Register as new admin. Remove old Windows bars; no new fields.
- `public/projects/hij-car-rentals-redesign.png`: Landscape H.I.J. catalog with light ivory workspace, navy sidebar and amber controls. Preserve rental navigation, car catalog, existing prices, availability, capacities, Reserve and Rent. Replace the visible account email with Welcome back. No added filters or promotional copy.

All six generated outputs were inspected for readable controls and saved in the workspace. Clicking a portfolio thumbnail opens the redesign at full size.
